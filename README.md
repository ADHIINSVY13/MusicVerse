# 🎵 MusicVerse – Lyrics Search Website

A frontend-focused music lyrics search platform built using **HTML**, **CSS**, **JavaScript**, and **Python**.

---

## 🔗 Live Demo  
👉 **Try the website here:**

## ✨ Features

- 🔍 **Search any song by title**  
- 🎤 **Displays song lyrics in a clean and readable layout**  
- 📱 **Responsive and user-friendly design**  
- 🎶 **Smooth animations and transitions**
